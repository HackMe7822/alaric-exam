Microsoft 365 / Azure Graph API — Setup Guide ▼
1

Register an Azure App & get your credentials

Open Azure Portal → Azure Active Directory → App registrations → New registration.

FieldValue
NameAlaric-Exam-Mail
Supported account typesAccounts in this org directory only
Redirect URILeave blank

After creating, copy Application (Client) ID and Directory (Tenant) ID — paste them in the fields above.

Go to Certificates & secrets → New client secret → copy the Value immediately (shown once only).

2

Grant Mail.Send API permission

In your app → API permissions → Add a permission → Microsoft Graph → Application permissions.

PermissionTypeWhy
Mail.SendApplicationRequired to send email on behalf of a mailbox

Click Grant admin consent — status must show a green checkmark.

⚠️ Do not add Mail.ReadWrite or Mail.Read — only Mail.Send is needed and fewer permissions is safer.
3

Create a Mail-Enabled Security Group (M365 Admin Center)

Open admin.microsoft.com → Teams & groups → Active teams & groups → Security → Add a security group.

FieldValue
NameAlaric-Exam-Mail-Senders
DescriptionAllowed mailbox for Alaric Exam email
TypeMail-enabled security group

Add only your From Email address (e.g. noreply@yourdomain.onmicrosoft.com) as the sole member.

🚫 Do not add admin accounts or other users to this group — this group defines which mailbox the app is allowed to send from.
4

Connect Exchange Online PowerShell (one-time setup)

Open PowerShell as Administrator and run:

# Install Exchange module (skip if already installed) Install-Module ExchangeOnlineManagement # Connect (login with Global Admin account) Connect-ExchangeOnline

Also install Microsoft Graph module to look up your group ID:

Install-Module Microsoft.Graph -Scope CurrentUser -Force Connect-MgGraph -Scopes "Group.Read.All" # Verify the group — SecurityEnabled and MailEnabled must both be True Get-MgGroup -Filter "displayName eq 'Alaric-Exam-Mail-Senders'" | Select Id,DisplayName,MailEnabled,SecurityEnabled
5

Apply Application Access Policy (critical security lock)

This restricts your Azure app so it can only send from your designated mailbox — not from any mailbox in your tenant.

# Replace YOUR_APP_CLIENT_ID and YOUR_GROUP_EMAIL below New-ApplicationAccessPolicy ` -AppId "YOUR_APP_CLIENT_ID" ` -PolicyScopeGroupId "Alaric-Exam-Mail-Senders@yourdomain.onmicrosoft.com" ` -AccessRight RestrictAccess ` -Description "Restrict Alaric Exam app to noreply mailbox only"
6

Verify the policy (do not skip)

Test that the allowed mailbox passes and a blocked mailbox fails:

# ✅ Should return AccessGranted : True Test-ApplicationAccessPolicy ` -AppId "YOUR_APP_CLIENT_ID" ` -Identity "noreply@yourdomain.onmicrosoft.com" # ❌ Should return AccessGranted : False Test-ApplicationAccessPolicy ` -AppId "YOUR_APP_CLIENT_ID" ` -Identity "admin@yourdomain.onmicrosoft.com"
✅ If the allowed mailbox returns AccessGranted : True and the admin returns AccessGranted : False — your security setup is complete.

Once verified, paste your Tenant ID, Client ID, and Client Secret in the fields above, enter your From Email, and click Save Config then Activate.
