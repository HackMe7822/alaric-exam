Resend Setup Guide ▼
1

Create a free account

Go to resend.com and sign up. The free plan includes 3,000 emails/month.

2

Add and verify your domain

Go to Domains and add your sending domain (e.g. yourdomain.com). Add the DNS records shown. You can also use onboarding@resend.dev to test without a domain.

3

Create an API key

Go to API Keys → Create API Key. Select Sending access. Copy the key and paste it above.

4

Set From Email

Use an address on your verified domain, e.g. noreply@yourdomain.com. Save and click Test Connection to verify.

SendGrid uses HTTP API — works on all cloud hosts. Free tier: 100 emails/day.

Must be verified in your SendGrid Sender Identity
SendGrid Setup Guide ▼
1

Create a free account

Go to sendgrid.com and sign up. Free tier: 100 emails/day.

2

Verify a Sender Identity

Go to Settings → Sender Authentication. Verify either a single sender email or a full domain. The From Email above must match a verified identity.

3

Create an API key

Go to Settings → API Keys → Create API Key. Choose Restricted Access and enable Mail Send. Copy the key and paste it above.

4

Save and test

Save the account and click Test Connection to verify the API key is valid.

Token is obtained automatically via client credentials flow. No OAuth redirect needed.
Leave blank to keep existing secret unchanged
Microsoft 365 / Azure Graph API — Setup Guide ▼
1

Register an Azure App & get your credentials

Open Azure Portal → Azure Active Directory → App registrations → New registration.

FieldValue
NameAlaric-Exam-Mail
Supported account typesAccounts in this org directory only
Redirect URILeave blank

After creating, copy Application (Client) ID and Directory (Tenant) ID. Go to Certificates & secrets → New client secret → copy the Value immediately (shown once only).

2

Grant Mail.Send API permission

In your app → API permissions → Add a permission → Microsoft Graph → Application permissions.

PermissionTypeWhy
Mail.SendApplicationRequired to send email on behalf of a mailbox

Click Grant admin consent — status must show a green checkmark.

⚠️Do not add Mail.ReadWrite or Mail.Read — only Mail.Send is needed.
3

Create a Mail-Enabled Security Group (M365 Admin Center)

Open admin.microsoft.com → Teams & groups → Active teams & groups → Security → Add a security group. Add only your From Email as the sole member.

🚫Do not add admin accounts — this group defines which mailbox the app is allowed to send from.
4

Connect Exchange Online & apply Application Access Policy

Open PowerShell as Administrator:

Install-Module ExchangeOnlineManagement Connect-ExchangeOnline # Replace YOUR_APP_CLIENT_ID and group email below New-ApplicationAccessPolicy ` -AppId "YOUR_APP_CLIENT_ID" ` -PolicyScopeGroupId "Alaric-Exam-Mail-Senders@yourdomain.onmicrosoft.com" ` -AccessRight RestrictAccess ` -Description "Restrict Alaric Exam app to noreply mailbox only"
5

Verify the policy

# Should return AccessGranted : True Test-ApplicationAccessPolicy -AppId "YOUR_APP_CLIENT_ID" -Identity "noreply@yourdomain.com" # Should return AccessGranted : False Test-ApplicationAccessPolicy -AppId "YOUR_APP_CLIENT_ID" -Identity "admin@yourdomain.com"
✅If noreply returns True and admin returns False — setup is complete. Fill in the fields above and click Save.
